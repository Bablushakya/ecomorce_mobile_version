CUSTOMIZATION QUICK TIPS
=========================

Change Colors:
  Edit CSS variables in styles.css (lines 9-19)

Add Products:
  1. Add product HTML in index.html (line ~500+)
  2. Update product data in app.js (line ~20)
  3. Add to button rendering function (line ~180)

Change Content:
  Edit text directly in index.html sections

Add Images:
  1. Place images in assets/images/
  2. Update src attributes in HTML
  3. Use relative paths: assets/images/filename.jpg

Modify Cart Behavior:
  Edit functions in app.js:
  - addToCart() at line ~120
  - updateQty() at line ~145
  - renderCartUI() at line ~195
